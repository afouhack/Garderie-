# QR Garderie

Petite appli web (une seule page HTML) pour garder sur son téléphone une photo du QR code de chaque enfant à la garderie : fiche par enfant, recadrage de la photo, affichage plein écran sur fond blanc.

Aucun QR code n'est stocké dans ce dépôt : les photos restent sur l'appareil (et dans l'espace privé de l'utilisateur).
